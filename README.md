# Soil to Soul Website

This is a first MVP website for an organic farming platform starting with one farm in Rangpur, Shilarpur district, Bulandshahr.

## Current scope

- Landing page for the farm brand
- Organic trust and traceability storytelling
- Produce showcase
- Demo live sensor dashboard section
- Future farmer onboarding section
- Customer interest form

## Files

- `index.html` - main website structure
- `styles.css` - responsive styling and visual identity
- `script.js` - navigation and demo interactions

## Next build phases

1. Convert this into a Django project.
2. Add real products, crop batches, and orders.
3. Create admin pages for farm updates.
4. Add Arduino or ESP32 API endpoints for sensor data.
5. Build farmer registration and verification workflows.
